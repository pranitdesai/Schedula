# 📅 Schedula

**Schedula** is a Flutter-based productivity and lifestyle management app designed to help users organize their daily schedules, activities, and personal routines in one place.

## ✨ Features

* 📆 **Schedule Management** – Create and manage daily activities and schedules.
* 🔐 **Firebase Authentication** – Secure user authentication and account management.
* ☁️ **Firebase Integration** – Store and manage user-related data using Firebase.
* 📱 **Cross-Platform** – Built with Flutter for Android and other supported platforms.
* 🎨 **Simple & User-Friendly UI** – Designed to keep everyday planning easy and accessible.

## 🛠️ Tech Stack

* **Frontend:** Flutter & Dart
* **Backend:** Firebase
* **Authentication:** Firebase Authentication
* **Database:** Firebase Realtime Database
* **Platform:** Android / Cross-platform

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Flutter SDK
* Dart SDK
* Android Studio
* Git
* A Firebase project

### Installation

Clone the repository:

```bash
git clone https://github.com/pranitdesai/schedula.git
```

Navigate to the project:

```bash
cd schedula
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```

## 📁 Project Structure

```text
lib/

├── ScheduleDisplay/       # Schedule-related screens
├── Utils/                 # Utilities and app configuration
├── Wrapper/               # Authentication/navigation logic
├── main.dart              # Application entry point
```
